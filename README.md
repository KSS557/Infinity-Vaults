# Infinity Vaults

### Eu

### This mod is designed for players who want more control over the Vault.


The mod allows you to configure the Vault’s cooldown or disable it, just like in vanilla Minecraft. The default setting is 36,000 ticks, which is equivalent to 30 minutes.

Many people believe that when you open a Vault, the item that was displayed when you opened it drops out. In vanilla Minecraft, this isn’t the case, but in this mod, you can enable or disable this setting. The default is true; to disable this setting, use false.

All settings can be changed in the config/infinityvaultsconfig.properties file.

### Commands

The mod also includes commands to clear the Vault. Type:

`/infinityvaults clear` - this will clear the Vault you are currently viewing

`/infinityvaults clear [<pos>]` - you can clear the Vault at the specified coordinates

`/infinityvaults clear [<player>]` - you can clear only the specific player in the Vault you are currently viewing

`/infinityvaults clear [<pos>] [<player>]` - you can clear the Vault at the specified coordinates for a specific player


### Ru

### Этот мод предназначен для игроков, которые хотят получить больше контроля над хранилищем.


Мод позволяет настроить время перезарядки хранилища или отключить его, как в базовой версии Minecraft. По умолчанию установлено значение 36 000 тиков, что соответствует 30 минутам.

Многие считают, что при открытии хранилища из него выпадает тот предмет, который был в нем отображен в момент открытия. В стандартной версии Minecraft это не так, но в этом моде вы можете включить или отключить эту настройку. По умолчанию установлено значение true; чтобы отключить эту настройку, используйте false.

Все настройки можно изменить в файле config/infinityvaultsconfig.properties.

### Команды

Мод также включает команды для очистки хранилища. Введите:

`/infinityvaults clear` — это очистит хранилище, которое вы просматриваете в данный момент

`/infinityvaults clear [<pos>]` — вы можете очистить хранилище по указанным координатам

`/infinityvaults clear [<player>]` — вы можете очистить хранилище только для конкретного игрока в том хранилище, которое вы просматриваете в данный момент

`/infinityvaults clear [<pos>] [<player>]` — вы можете очистить хранилище по указанным координатам для конкретного игрока
